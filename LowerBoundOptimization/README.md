# Fractional Partition Optimization

Open `simple_minlp.py` in VS Code and click the Python Run button.

Edit these values near the top of the file:

```python
m = 6
a = 1 / 4
b = 1.0
l_bound = 10.0
max_nodes = 10_000
```

The script automatically restarts using the `.venv` in the root of the
`Thesis-Template` project.

To reinstall the dependency manually from the project root:

```bash
.venv/bin/python -m pip install -r fractional_partition_optimization/requirements.txt
```

\noindent
The runs used \(b=1\), \(0\leq l_i\leq 30\), group and denominator
tolerance \(10^{-5}\), and a limit of 20000 branch-and-bound nodes. The
auxiliary objective variable used the valid upper bound
\[
  r\leq 1+\frac{1}{6a}.
\]
The cases \((m,a)=(3,\frac12)\) and \((6,\frac12)\) ended with SCIP
status \texttt{optimal}. Every other run ended with status
\texttt{nodelimit}; those entries are the best feasible objectives
returned by these fresh runs within the node limit and are not
certificates of global optimality.
